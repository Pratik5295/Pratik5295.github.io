Figma → Unity Color Converter

Offline & Free No Dependencies Unity UI Toolkit

What this tool is

When you build UI in Unity's UI Toolkit with the project set to Linear color space, semi-transparent colors don't blend the way they do in Figma. Figma composites alpha in gamma / sRGB space, while Unity blends the same color in linear space. The result: a panel that looks like a clean 35% black scrim in your design comes out visibly lighter and weaker in the built game.

This converter solves the exact alpha (and gives a matching hex) you need to type into Unity so a Figma color reproduces pixel-for-pixel on the target background — no more eyeballing values until it "looks close enough."

Why I built it

While matching a mobile UI to its Figma spec, semi-transparent greys kept coming out wrong in Unity. I looked for an existing site that would take a Figma value like #00000059 and hand back the Unity Linear equivalent — and there wasn't one. The closest tools each solved only half of the problem:

Existing toolWhat it doesWhat it's missing
Alpha blending calculators Blend a foreground + alpha over a background and show the resulting visible color. Never gives you the Unity Linear equivalent alpha to type back in.
sRGB → Linear converters Convert channel values between sRGB and linear. Useful for checking the math. Don't solve the alpha-blend problem at all.
Unity "Force Gamma" on Panel Settings Renders UI Toolkit in gamma in specific render-texture workflows. Only applies to certain setups and can carry performance / bandwidth costs, so it isn't a universal fix.

So I wrote a tiny, dependency-free converter that does the one missing step, and packaged it here as a proper offline tool with a live preview and a transparent math breakdown you can verify.

How to use it

  • Figma foreground color — paste straight from Figma. Accepts #RRGGBBAA, #RGB, rgb(), rgba(), and modern rgb(0 229 191 / 40%) syntax.
  • Background color behind it — the actual card or page color the element sits on. The correct answer depends on this, so set it to the real surface (default is white).
  • Read the Recommended Unity UI Toolkit value. For greyscale colors you keep the same RGB and the alpha increases; for saturated colors the tool warns you and offers an exact baked opaque fallback.

Example: Figma overlay #00000059 on a white background converts to roughly #0000009E in Unity Linear — same black, higher alpha, matching visible result.

Math breakdown

Figma-style blending is calculated in sRGB/gamma-like color values:

FigmaResult = Foreground × FigmaAlpha + Background × (1 - FigmaAlpha)

Unity Linear blending happens after converting sRGB values into linear values. To match the Figma result, this tool solves the alpha needed in linear space:

UnityAlphaChannel =
    (Linear(FigmaResult) - Linear(Background))
    /
    (Linear(Foreground) - Linear(Background))

When the foreground is greyscale over a greyscale background, R/G/B usually solve to the same alpha. For saturated colors like rgba(0, 229, 191, 0.4), each channel can want a different alpha. Since one UI color only has one alpha, the tool gives a best-fit alpha and also gives an exact baked opaque fallback.
