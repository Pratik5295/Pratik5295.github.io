How the calculation works

The target uses an sRGB alpha blend over an opaque background:

Target = Foreground × Alpha + Background × (1 − Alpha)

The solver then finds the alpha needed to approximate that target when blending in linear space:

Alpha per channel =
  (Linear(Target) − Linear(Background)) /
  (Linear(Foreground) − Linear(Background))

Some colors need a different alpha for each RGB channel. The default strategy finds a single best-fit alpha while preserving RGB. The opaque alternative uses the target composite, rounded to 8-bit channels.

Using the result

  1. Enter the foreground color and its opacity from your design.
  2. Set the opaque background the element will sit on.
  3. Copy the suggested value and compare it in your Unity UI.

For example, #00000059 over white gives an alpha of approximately 0.6187, or #0000009E, in this model.

Check your rendering setup

The calculation assumes sRGB source values and linear blending. Unity supports both linear and gamma workflows, so confirm which your project uses before applying an adjustment.

For UI Toolkit render textures, PanelSettings.forceGammaRendering applies only in specific linear-project and texture-format configurations.
